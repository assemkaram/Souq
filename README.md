# Souq

A simple shopping web app inspired by the Arabic word *souq* (سوق), meaning "marketplace." Built with plain HTML, CSS, and JavaScript, with no build step or dependencies.

**Live demo:** https://assemkaram.github.io/Souq/

## Features

- Browse a set of products in a storefront layout
- Responsive design that runs entirely in the browser
- No frameworks or external libraries required

## Project Structure

```
Souq/
├── index.html                                   # Main page
├── style.css                                    # Styles
├── app.js                                       # Product logic
└── pngtree-shopping-cart-convenient-...jpg      # Image asset
```

## Getting Started

### Option 1: Use the live demo

Open https://assemkaram.github.io/Souq/ in your browser.

### Option 2: Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/assemkaram/Souq.git
   ```
2. Open the project folder:
   ```bash
   cd Souq
   ```
3. Open `index.html` in your browser. No server or installation is needed.

## Usage

Open the page and browse the products.

## Customizing

To change the products, edit the product data in `app.js` and update the markup in `index.html` if needed. Adjust colors and layout in `style.css`.

## Deployment

The site is hosted with GitHub Pages from the `main` branch. To deploy your own copy, go to **Settings → Pages**, select the `main` branch as the source, and save.
